LINKZZZ ASSET LIFECYCLE PATCH

Extract over the project root and allow existing files to be overwritten.

Run in this order:
  npx.cmd prisma generate
  npx.cmd prisma migrate deploy
  npm.cmd run typecheck
  npm.cmd test
  npm.cmd run lint
  npm.cmd run build

The migration adds foreign keys from Profile.avatarAssetId,
Profile.coverAssetId and Link.imageAssetId to Asset. Before adding constraints it
sets only invalid/mismatched legacy IDs to NULL; existing image URLs are not
modified.

New uploads retain their Asset IDs. Profile saves validate asset ownership and
type. Replaced or removed assets are deleted only after a successful profile
transaction. Failed profile saves request cleanup of newly uploaded, unreferenced
assets; cleanup is ownership-scoped and never deletes an asset still referenced
by a profile or link.
